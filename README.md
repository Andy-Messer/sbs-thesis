# Оценка мультимодальных LLM-систем с помощью LLM-as-a-Judge

Магистерская диссертация о воспроизводимом сравнении двух мультимодальных LLM-систем с помощью моделей-судей и асессорской разметки. Работа рассматривает, повышают ли несколько промптов или ансамбль судей согласие автоматической оценки с оценкой людей.

## Подход

- Сравниваются single-judge, multi-prompt и consensus-схемы в единой модели голосования.
- Для попарного сравнения используется SbS-NPS с bootstrap-доверительными интервалами; результаты сопоставляются с асессорской разметкой и оценкой стоимости.
- Протокол включает версионирование моделей и промптов, фиксацию параметров и повторные прогоны.

## Основные результаты

- В основном текстовом эксперименте на 50 примерах ни multi-prompt, ни consensus не показали статистически значимого роста согласия с асессорами относительно single-judge. Отсутствие значимости не доказывает отсутствия эффекта: выборка мала.
- В исследованных условиях consensus из четырёх судей значимо отклонялся от асессорской оценки SbS-NPS. Смещение в пользу более развёрнутых ответов оставалось проблемой.
- Проведён отдельный мультимодальный ablation study на 200 примерах с тремя повторными прогонами. Экспериментальная метрика C.R.A.P. не показала различающей способности в этой проверке.

Выводы ограничены размером выборок и набором близких семейств открытых моделей; визуальная часть представлена статичными скриншотами. Межасессорская согласованность на golden set не измерена. В главе результатов ранние прогоны с дефектным извлечением ответа отмечены как диагностические, а часть результатов — как предварительная. Подробнее: [результаты](sections/05-results.tex) и [заключение](sections/06-conclusion.tex).

## Сборка

Нужен дистрибутив LaTeX (TeX Live / MiKTeX) с `pdflatex` и `biber`.

```sh
make            # pdflatex -> biber -> pdflatex x2; результат: main.pdf
make clean      # удалить промежуточные артефакты
make watch      # авто-пересборка через latexmk, если установлен
```

Корневой файл — `main.tex`, библиография — `bibliography.bib`, макросы — `preamble.tex`. Вёрстка использует шаблон МФТИ `mipt-thesis-ms`; шаблонные файлы взяты из [yl3dy/mipt-thesis](https://github.com/yl3dy/mipt-thesis) (MIT, см. `LICENSE-mipt-thesis`).
